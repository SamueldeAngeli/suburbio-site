# Área Crypto

Pacotes: 50, 100, 150, 200, 300, 400, 500, 700 e 1000 Crypto a 120 centavos por unidade. Personalizado: 125 centavos por unidade, inteiro positivo dentro de CRYPTO_CUSTOM_MIN/MAX. Padrões 1 e 100000, teto contratual 1000000. Até dez unidades por linha.

Preço do browser é estimativa. API calcula centavos e rejeita preços recebidos. Cupom reduz apenas valor financeiro: 300 Crypto com 15% custam R$306; snapshot mantém entrega de 300 Crypto.

API habilitada indisponível não vira catálogo fictício. Compra in-game, carteira e crédito efetivo dependem do fulfillment/bridge pendentes. O nome deste documento é técnico; a interface apresenta Crypto e Área VIP.
